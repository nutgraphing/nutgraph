# Nutgraph

WordPress-plugin: een whiteboard met plakbriefjes om verhaalstructuren te bouwen.
Alle gegevens blijven in de browser van de gebruiker.

- Shortcode: `[nutgraph]`
- Updates: WordPress haalt nieuwe versies op uit de releases van deze repository.
- Nieuwe versie uitbrengen: verhoog het versienummer (zie `CLAUDE.md`) en zet de wijziging op `main`.
